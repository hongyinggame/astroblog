### <a href = 'https://leetcode.cn/problems/battleships-in-a-board/'>棋盘上的战舰</a>
&emsp;&emsp;两种方法都自己想出，一种是将舰队多余舰数删除，避免统计时被迷惑，另一种就是判断左边与上边是否为空来进行判断是否为舰队，注意：特殊的为第一行与第一列。
```
第一种
public int countBattleships(char[][] board) {
        int count =0;
        for(int i =0; i<board.length; i++){
            for(int j =0; j<board[i].length; j++){
                if(board[i][j]=='X'){
                    count++;
                    if(i+1<board.length&&board[i+1][j]=='X'){
                        for( int m = i+1;m<board.length;m++){
                            if(board[m][j]=='X'){
                                board[m][j]='.';
                            }else{
                                break;
                            }
                        } 
                    }
                    if(j+1<board[i].length&&board[i][j+1]=='X'){
                        for( int m = j+1;m<board[i].length;m++){
                            if(board[i][m]=='X'){
                                board[i][m]='.';
                            }else{
                                break;
                            }
                        } 
                    }
                }
            }
        
        }
        return count;
    }

                        }

                        }

        }
```
